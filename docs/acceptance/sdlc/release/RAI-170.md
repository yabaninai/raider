# RAI-170 independent local-release acceptance

This verifier exercises the integrated `ReleaseStage` and `LocalReleaseHandler` from disposable Git repositories. It does not contact a remote or perform publication/deployment. The fixture has no configured Git remote; tag and artifact observations are made locally.

## Coverage map

| Acceptance ID | Surface and independent assertions |
| --- | --- |
| SDLC-VREL-01 | `LocalReleaseHandler` accepts parsed check, review, and integration records for one candidate and policy, with a live `CheckpointDispatch`. The handler derives the release evidence from those records. `ReleaseStage` creates `artifacts/release/3.4.5/{CHANGELOG.md,release.json,SHA256SUMS}` and local `v3.4.5`. The verifier recomputes each listed SHA-256 from file bytes, checks provenance's local-only marker, checks the persisted typed result's candidate digest, and round-trips the record through `run.json` and `events.jsonl`. The fixture has no remote configuration and the local release API exposes only local Git operations. |
| SDLC-VREL-02 | Integration evidence with a foreign policy, evidence bound to a different candidate digest, absent evidence, rejected checks, absent/denied/expired/stale checkpoint authorization, duplicate version, pre-existing tag, invalid SemVer, and build failure are all refused. Each case checks no new artifact directory or version tag. Duplicate release preserves the already-installed changelog/tag. |
| SDLC-VREL-03 | Interrupts in `afterStagedArtifacts`, after staged files exist but before installation. The typed `ReleaseStage.Interrupted` reconciliation reports the staged inventory; the installed version directory and local version tag remain absent. Reconciliation does not resume materialization. |

The repetition matrix is the complete `LocalReleaseAcceptanceSpec` suite: normal 1/1, adversarial 2/2, interruption 1/1, all run together three consecutive times. The matrix's local-only boundary is checked by a disposable repository with no remotes and by the fixed local Git operations in `ReleaseStage`; it is not a hosted-forge or network syscall monitor.

## M4 mapping and boundary

The release result is local provenance for the accepted candidate, not a published release. The acceptance closes the SDLC-05 local-release prerequisite in the ADR-030 SDLC line. It does not establish hosted forge behavior, package/image publication, deployment, signing, or a platform distribution matrix.

Executable suite: `raider.cli.release.verification.LocalReleaseAcceptanceSpec`.
