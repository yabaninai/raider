## Diff-обоснование построчно

1. **`HINT_BAR` (:90-91 → :98-99)** — литерал `"...:state <scope> :help :quit"`
   → `"...:state <scope> :aux :help :quit"`. Причина: продуктовый
   `TabBarRenderer.hintBar` (тот же коммит `6897827`, `:aux` — LIN-04A,
   `CommandRouter` регистрирует `:aux`) рендерит палитру с `:aux`;
   эмпирика RAI-112: 1120 вхождений строки с `:aux` в транскрипте, матчей
   литерала probe — 0 → критерий `hints >= 500` был недостижим независимо от
   статус-паттерна (hints=0 в `tabs-pty-summary.json` RAI-112). Сравнение
   осталось byte-exact full-line equality (`ln.strip() == HINT_BAR`) — сила
   оракула не изменена. Это сопутствующий литерал сообщения, не статус-паттерн;
   без него PROBE-01 (all_pass) недостижим — вынесено явно для review.
2. **`ROW_RE` (:92 → :100-112)** — `^[* ]\d+\. \S+ \[(Queued|Running)\](
   \(\d+ unread\))?$` → грамматика канонического StatusText
   `<body> | <counters>`:
   - body: `queued | running | cancelling | waiting(<reason|unknown>) |
     terminal <status> | tool <name>` — ровно словарь `StatusText.body`:
     `JobStatus` = {Queued, Running, Waiting, WaitingApproval, Cancelling} ∪
     Terminal {Succeeded, Failed, Cancelled, Interrupted, Uncertain};
     `waitingText` → lowercase reason из `WaitReason` {slot, admission,
     approval, budget, childslot, backpressure} ∪ `unknown` (UNI-02);
     `tool \S+` — `toolText(tool)`;
   - counters: `cost unknown | cost \$\d+\.\d{6}` (+ опционально
     `, tail \+\d+ lines/\+\d+ chars`) — ровно `StatusText.counters`
     (honest: unknown никогда не рендерится как $0);
   - хвост строки `(\(\d+ unread\))?` — без изменений (TabBarRenderer :19-21).
   Регекс проверен фикстурами: 11 позитивных рендеров StatusText (все ветки
   body/counters) — fullmatch; 9 негативных (legacy `[Running]`, оборванная
   строка без `]`, `$0`-подобные/бессловесные/выдуманные статусы, unread без
   счётчика, `terminal` без статуса, unknown reason) — НЕ fullmatch.
   Fullmatch-семантика и кандидат-эвристика `scan_bar` (:317-326) не менялись —
   любая порванная/чужеродная строка бара по-прежнему считается malformed.
3. **`ok_live` (:370 → :385)** — `wait_for("*1. tab1 [Running]")` →
   `wait_for("*1. tab1 [running | cost unknown]")`. В этой точке сценария tab1
   в фокусе (`*`), в creation order строка №1, статус Running (фидер завершился:
   1×JobStatusChanged(Queued→Running) + 220×Diagnostics на вкладку), activeTool
   пуст → body `running`, usage unknown → `cost unknown`. Той же силы: тот же
   tab, тот же фокус-маркер, тот же статус (honest-рендер), тот же таймаут 15 c.
4. **Sequencing-guard после `ok_live` (:386-392) — SCOPE-NOTE, флаг для
   независимого review.** Добавлен `s.pump(0.5)` перед `send(":quit\r")`.
   Воспроизведено 2/2 прогонов ДО фикса: pty-эхо набранного `:quit` вклеивалось
   в ещё не дочитанный хвост printAbove-эмиссии бара — cleaned-транскрипт давал
   строку ` 2. tab2 [running | cost unknown]:quit` → `bad_rows=1` → PTY-01 FAIL
   (обе точки вставки идентичны: между row2 и row3). Это гонка транскрипта, а не
   дефект продукта: та же гонка существует в legacy-probe (зелёный legacy-транскрипт
   в root просто не стрельнул, tears=0). Guard только дренирует in-flight байты
   рендера перед выходом; ни один паттерн, ассерт или критерий all_pass не
   изменён (тот же класс, что существующие `s.pump(0.3)` после `:switch`).
   Формально это за буквой «только статус-паттерны/сообщения» — потому явно
   задокументировано здесь и в коде; при отклонении review откат — одна строка.

## Limitations / blockers

- **Независимое review обязательно и пока отсутствует** — изменение защищённого
  верификатора. Два пункта на решение reviewer'а: (1) `HINT_BAR` —
  сопутствующий литерал палитры, не статус-паттерн (без него PROBE-01
  недостижим: hints=0/1120 в RAI-112); (2) `pump(0.5)` guard — sequencing-фикс
  за буквой «только статус-паттерны» (reproducer: прогоны 1/2, bad_rows=1,
  идентичная точка вставки). Оба не ослабляют ни одного оракула; откат обоих —
  тривиален.
- PTY-03 в негативной копии упал ДОПОЛНИТЕЛЬНО к ожидаемому (raiderCli/test
  rc=1): `java.lang.IllegalStateException: no artifacts/tools/m2` —
  environmental-артефакт временной копии (artifacts/ исключён из rsync),
  НЕ следствие инжектированного дефекта (дефект в raiderUi test-scope).
  Негатив доказан PTY-01/02 (точная сигнатура потери). В product-дереве
  bootstrap на месте — все PTY-03 зелёные (A/B/C).
- Exit-код прогона 1 не зафиксирован напрямую (tee-пайп); зафиксирован его
  summary (`all_pass=false`, «tests: 2/3 passed») — exit=1 детерминирован кодом
  `main()`. Прогоны 2/A/B/C/негатив — с прямым захватом exit.
- Артефакты вне git; evidence привязан к commit `8dcf8dc` (lane). Финальная
  приёмка — на интегрированном кандидате после merge (coordinator).
- Известное ограничение probe не менялось: атомарность проверяется по
  финальному cleaned-транскрипту (race артефакты вида «tear, стёртый JLine»,
  не детектируемы индивидуально); resize-проверка доказывает no-crash +
  integrity, не пиксельный reflow.
