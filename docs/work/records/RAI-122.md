## Line-by-line diff rationale

1. **`HINT_BAR` (:90-91 → :98-99)** — literal `"...:state <scope> :help :quit"`
   → `"...:state <scope> :aux :help :quit"`. Product `TabBarRenderer.hintBar`
   (same commit `6897827`; `:aux` is LIN-04A, registered by `CommandRouter`)
   renders the palette with `:aux`; RAI-112 empirical result: 1120 occurrences
   of a line containing `:aux` in transcript, 0 matches for probe literal →
   `hints >= 500` was impossible regardless of status pattern (hints=0 in
   RAI-112 `tabs-pty-summary.json`). Comparison remains byte-exact full-line
   equality (`ln.strip() == HINT_BAR`) — oracle strength unchanged. This is a
   related message literal, not a status pattern; without it PROBE-01
   (`all_pass`) is unreachable — called out explicitly for review.
2. **`ROW_RE` (:92 → :100-112)** —
   `^[* ]\d+\. \S+ \[(Queued|Running)\](
   \(\d+ unread\))?$` → grammar of
   canonical StatusText `<body> | <counters>`:
   - body: `queued | running | cancelling | waiting(<reason|unknown>) |
     terminal <status> | tool <name>` — exactly `StatusText.body` vocabulary:
     `JobStatus` = {Queued, Running, Waiting, WaitingApproval, Cancelling} ∪
     Terminal {Succeeded, Failed, Cancelled, Interrupted, Uncertain};
     `waitingText` → lowercase reason from `WaitReason` {slot, admission,
     approval, budget, childslot, backpressure} ∪ `unknown` (UNI-02);
     `tool \S+` — `toolText(tool)`;
   - counters: `cost unknown | cost \$\d+\.\d{6}` (optionally
     `, tail \+\d+ lines/\+\d+ chars`) — exactly `StatusText.counters`
     (honest: unknown is never rendered as $0);
- line suffix `(\(\d+ unread\))?` unchanged (TabBarRenderer :19-21).
   Regex checked with fixtures: 11 positive StatusText renders (all body/counter
   branches) fullmatch; 9 negative (legacy `[Running]`, truncated line without
   `]`, `$0`-like/wordless/invented statuses, unread without counter, `terminal`
   without status, unknown reason) do NOT fullmatch. Fullmatch semantics and
   candidate heuristic `scan_bar` (:317-326) unchanged — any torn/foreign bar
   line is still malformed.
3. **`ok_live` (:370 → :385)** — `wait_for("*1. tab1 [Running]")` →
   `wait_for("*1. tab1 [running | cost unknown]")`. At this point tab1 is
   focused (`*`), row #1 in creation order, status Running (feeder finished:
   1×JobStatusChanged(Queued→Running) + 220×Diagnostics to tab), activeTool
   empty → body `running`, usage unknown → `cost unknown`. Same strength: same
   tab, same focus marker, same status (honest rendering), same 15s timeout.
4. **Sequencing guard after `ok_live` (:386-392) — SCOPE NOTE, flag for
   independent review.** Added `s.pump(0.5)` before `send(":quit\r")`.
   Reproduced in 2/2 runs BEFORE fix: PTY echo of typed `:quit` was joined to
   the unread tail of bar printAbove emission — cleaned transcript yielded
   ` 2. tab2 [running | cost unknown]:quit` → `bad_rows=1` → PTY-01 FAIL (both
   insertions identical: between row2 and row3). Transcript race, not product
   defect: same race exists in legacy probe (green legacy transcript in root
   simply did not hit it, tears=0). Guard only drains in-flight render bytes
   before exit; no pattern, assertion, or `all_pass` criterion changed (same
   class as existing `s.pump(0.3)` after `:switch`). Technically outside the
   letter of “status patterns/messages only,” so explicitly documented here and
   in code; if review rejects it, revert is one line.

Untouched (functional oracles): `feeds_predicate` (report read model, 1105
events = 5×221, `status=="Running"` is report enum name, not rendering),
drafts byte-exact (2 turns, echoes once), scrollback == 220 exact lines,
scrollbackEvicted==0, history 200 + honest eviction 22, hubDroppedDiagnostics==0,
`rows >= 2000`, `hints >= 500`, exit 0, PTY-02 (resize/paste/Ctrl+C/TERM=dumb),
PTY-03 (raiderCli/test + raiderRuntime/test green), all_pass criterion, machine
summaries (`tabs-pty-summary.json`, `m1-demo-summary.json`).
