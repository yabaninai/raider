Status: partial pending final gates and review. Date: 2026-10-18. Baseline commit/source: 149f07d (lane HEAD before edits: a3df2d2109a3905ef025ba937104d207dfc2e81a; main merged from 07e7e28 as 6ab5c0d).

## Resulting behavior

Headless artifact publication now writes immutable generation-specific data/source files and atomically replaces `lineage-commit.json` last. The pointer names both files and pins SHA-256 digests. `LineageSnapshot.read` validates the manifest, both files, both hashes, and the lineage-data document; it never falls back to fixed-name files. ReplayCli and the product replay command use this reader. Existing fixed-name artifacts remain available for compatibility, but are not the snapshot authority. The contract authorizes the local pinned dotc 3.9.0 validation on the source resolved from a committed snapshot; this compiles locally without provider calls and does not alter session exit semantics.

Frozen lineage schema and GraphHash normalization were not changed.

A raw read of legacy fixed-name artifacts is not a committed read; production replay no longer does this. Full suite must be rerun after the fixture correction; final gates are still pending.
