## Resulting behavior

OpenCode HTTP external backend adapter (`modules/backend-opencode`, standalone Scala 3 + ZIO module, no raiderCore dependency):

- Pinned slice of the OpenCode server API: `/global/event` SSE stream, session create/read/status, message list, `prompt_async`, `abort`, auth header, directory scoping.
- Wire decoding is pinned to `contracts/backends/opencode/expected/pinned-events.json` (SDK types.gen.ts v1.19.4 corpus snapshot `d7d85817160120fd59fb27ee6ff354f45d18b994`); unknown event types decode to pass-through `Unknown`, undecodable frames are typed `StreamProtocol` errors that force a reconnect; reconnects never replay a mutation.
- Run outcomes settle only from terminal server evidence; on settle deadline the adapter reconciles against the read-only message list and reports `reconciled = true`; missing completion evidence stays `Uncertain`. Acked server abort (`Aborted` with server evidence) is distinct from silent abort (`Uncertain`, no replay).
- Subscriptions register synchronously on the shared event bus before a mutating call is sent (`OcEventBus.subscribe`, `OcBackend.subscribeSessionQueue`), so run evidence emitted while the server processes the submission cannot be missed (the feed has no replay).
- Session-scoped views filter on session id and, when configured, the workspace directory: concurrent sessions from two roots do not cross-read.

Fixes made while taking the suite green (the lane's substantive changes):

- `OcEventBus`: synchronous `subscribe` added; `filtered` now builds on it. Previously `toQueueUnbounded` registered subscriptions asynchronously in a background producer fiber, so `prompt_async` could beat registration and lose all run evidence (observed `matching=0` publishes; every prompt test fell back to reconcile-only).
- Contract stand: `session.created` properties now carry the session object directly per the golden pin (`message.updated` keeps the `info` wrapper); the previous extra wrapper killed the reader on the first frame (`OC-STREAM: undecodable event frame`), forcing reconnect loops.
- Spec: `expect`/`expectFailure` and the empty-prompt check run under `Live.live` — with a frozen `TestClock`, `provideLayer(ZLayer.succeed(Clock.ClockLive))` alone does NOT unfreeze `ZIO.sleep`/`timeout` (services see ClockLive, time stays test-time); `Live.live` does. Abort tests subscribe via `subscribeSessionQueue` strictly before forking the prompt.
- `OcWireSpec` locates the pinned corpus by walking up from the test working directory when `RAIDER_REPO_ROOT` is absent, so the suite runs identically under sbt and `modules/backend-opencode/run-tests.sh`.
