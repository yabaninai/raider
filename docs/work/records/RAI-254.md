## Limitations / blockers

- **Environment risk for other lanes (owner attention):** Homebrew `openjdk` is now **JDK 27**, and `sbt` resolves it when `JAVA_HOME` is unset. A **cold** `raiderCli/Test` compile under JDK 27 crashes deterministically (dotc 3.9.0 cannot resolve `VarHandleDoubles$FieldStaticReadOnly` inner-class entries; LazyVals phase pulls `java.lang.invoke.VarHandle` from the JRT). The root checkout's gate runs tonight passed under Java 27 only because their zinc state was warm (no recompiled cli test sources). Fresh worktrees / clean builds will hit this until `JAVA_HOME` pins JDK 21 (or dotc/Scala is upgraded — separate card). My gate green is under Oracle JDK 21.0.12.1, the version prior records (e.g., RAI-244) cite.
