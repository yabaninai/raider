  staged layout and RAI-279's "nested layout preserved" contract; RAI-279's
  own evidence will pin the final staged names.
- Out-of-scope stale occurrences remain OUTSIDE the allowed paths and are
  disclosed for the coordinator: `docs/examples/first-use/README.md` still
  contains "The current CLI does not implement a general `--help` option:
  `raider --help` returns an unknown-subcommand error with exit 21" (and a

  says "the CLI does not currently support general `--help`" (that file is
