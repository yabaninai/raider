- **`fs_patch_multi` key semantics (on its tool line):** multi-file git-style diff (new, modified and deleted file sections) applied ALL-OR-NOTHING — every listed file is validated against its current sha256 before anything is written; if any check fails, nothing is applied; `expected_sha256` maps each changed path to its current sha256.
