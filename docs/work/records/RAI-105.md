## Limitations / blockers

- BLOCKER (чужой код, contract-change request): `TabShellHostPtySpec` (frozen,
  RAI-102) P2W-01 флэйчит в ПОЛНОМ sbt-test под высокой CPU-конкурентностью —
  теперь в raiderRepl три PTY-спеки. Root cause (точно установлен по
  транскриптам упавших прогонов, evidence:
  artifacts/rai-105/repro-ref/p2w01-torn/): драйвер шлёт `:quit` сразу после
  `s.waitFor("*1. alpha [", …)` (строка ~360), но эта подстрока присутствует
  в транскрипте с ЛЮБОГО более раннего pump-рендера бара — условие
  удовлетворяется мгновенно, `:quit` уходит, пока фидер ещё стримит
  (у torn-сессий в ряде бара бейдж «(189 unread)» при EventsPerTab=220), и
  echo `:quit` вклеивается в недописанный ряд: ` 2. beta [running…] (189
  unread):quit` → RowLike-нарушение → `bad=1` при `bad==0` (TabShellHostPtySpec
 .scala:396). Статистика: полный raiderRepl/test с моими спеками — 2/3 падений
  (894 rows, bad=1), без моих PTY-спек — 2/2 зелёных, изолированный testOnly —
  2/2 зелёных. Это НЕ порог и НЕ продуктовый код — это неоднозначная
  синхронизация тестового драйвера. Предлагаемый микрофикс (координатору,
  одна строка в TabShellHostPtySpec.p2w01): перед `s.send(":quit\r")` ждать
  уникальный маркер полной доставки — `s.waitFor("(221 unread)", 30.seconds)`
  (final pump-рендер при lastSeq==221), либо сбрасывать cleaned-буфер/ждать
  хвост блока (hintBar) после `:tabs`. Карточка RAI-105 править frozen-файл
  не вправе; до фикса полный гейт может потребовать 1–2 повторов.
- Точные промежуточные значения бейджа в PTY-транскрипте не проверяются:
  pump-рендер конкурентен bumpUnread (eventually-consistent) — это свойство
  принятого RAI-061 pump, задокументировано в спеке; точные значения —
  report-оракул.
- PTY-транскрипт-атомарность оценивается по финальному cleaned-транскрипту
  (тот же класс limitation, что принят в RAI-062/RAI-102).
- artifacts/tools/m2 (+cp-*.txt) скопированы в worktree из root (untracked,
  §1a) — требование гейта compile-fixtures; в git не попадают.
- docs/lineage.md §9.2 и board — вне allowed paths lane; обновляет координатор
  на merge (gap: продуктовая поверхность unread badges закрыта спеками этого
  lane).
