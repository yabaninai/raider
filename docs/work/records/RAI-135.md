## Why perf was deferred (honest finding)

`scripts/quality/ux_baseline.py` returns 0 whenever the report is written,
including when measurements are recorded as "skipped: no classpath"
(main() → "exit 0 iff the report is on disk"). Registering it as a gate would
let a skipped measurement pass a quality gate — violating the
skip-is-never-passed discipline (quality-gates §1/§2). Follow-up RAI-137
registered: harden harness exit semantics first (exit 0 only when
measurements completed; distinct non-zero exit + stderr reason on skip;
--allow-skip for informational runs), then register the perf profile.
