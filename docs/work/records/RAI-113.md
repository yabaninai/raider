## Resulting behavior

Interactive command `:scrollback [tabId]` on the product tabs-mode surface
(`raider repl --tabs`, RAI-108): renders a tab screen using product
`raider.repl.TabShellScrollback.screen`/`render` (RAI-104) ABOVE the prompt;
registration follows the freshness precedent in RAI-111; frozen layer
(modules/ui/**) untouched — existing seams were sufficient.

- `raider.repl.ScrollbackCommands` (product, NEW):
  - `names` — source-of-truth registry for the surface (`Vector(":scrollback")`);
    parser matches exactly the registry (no second hand-maintained list), and
    combined nearest-hint catalog (`ShellPalette.allCommands`) DERIVES from the
    registry (RAI-111 precedent). TAB completion remains router-only (the
    documented RAI-111 decision for non-router surfaces; pinned by the spec).
  - `parse` — pure matching (first token, case-insensitive, as in
    Commands.handle/PlanCommands); `:scrollbackx` is never a partial match.
  - `resolve` — token resolution over the public read model registry,
    with frozen `:switch` semantics: 1-based index, exact TabId, exact label,
    unique label prefix; EVERY failure (no token / out of range / unknown or
    ambiguous label) is TYPED `RegistryError.UnknownTab` with the raw token
    (P2SR-02); lookup does not create phantom tabs; missing token is
    `missingTab` = `UnknownTab(TabId(""))`, NOT a default to the focused tab
    (card contract: missing tabId = UnknownTab).
  - `run` — product read through `TabShellScrollback.screen` (typed
    `RegistryError` propagates as-is).
  - `commandTerminal` — terminal interceptor (RAI-110 pattern
    `PlanPanel.commandTerminal`): registry commands are consumed BEFORE the
    frozen router, and the result is printed as ONE atomic block through ONE
    writer (`printAbove`); the next line is read afterward; non-registry lines
    pass through byte-exactly; EOF passes through. Dispatch is INLINE (unlike
    `:approve`): registry reads are bounded and ungated — rendering
    deterministically lands before the next prompt redraw.
  - Output: success — exact `Screen.render` (header with evicted count +
    byte-for-byte window); failure — one line `error: <message>` (end-trimmed
    for transcript; typed value retains raw empty TabId).
- `raider.repl.TabShellHost` — additive overload `run(wiring, scrollback)`
  (plan-overload RAI-110/paletteTerminal RAI-106 pattern): decorates the
  palette terminal with the interceptor; previous overloads are byte-identical.
- `raider.repl.Main.runTabs` — product `--tabs` entry point starts the shell
  with the interceptor (`TabShellHost.run(wiring, ScrollbackCommands(registry))`).
  Legacy loop (without `--tabs`) untouched bit-for-bit (Commands/helpText/pipe/tty
  loop unchanged; `:scrollback` in legacy remains
  `unknown command … — try :help`).
- `raider.repl.ScriptedTabStream` — fixture-volume env controls
  (`RAI113_SCRIPTED_TAB_LINES`, `RAI113_SCRIPTED_TAB_DELAY_MS`; defaults
  220/15ms unchanged — all RAI-108 anchors remain). Mock-gated by construction:
  stream is forked ONLY when `PreludePlan.isScripted`; synthetic data never
  reaches a live backend. Needed for P2SR-01: 10k burst on the REAL entry point.
- `raider.repl.ShellPalette.allCommands` — += `ScrollbackCommands.names`
  (nearest suggestion: `:scrollbak` → did you mean: `:scrollback?`); catalogs
  `commands`/`chatCommands` and `complete`/`completeChat` unchanged.

  PTY family twice flaked on LINE-BY-LINE transcript counters (details in
