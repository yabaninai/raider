## Resulting behavior

`ReplSession.make` constructs one interpreter-world `EventHub` at `ReplSession.scala:90` and passes the same instance to `BudgetLedger.make` at line 91. It also builds the bound `PlanSession` and `PlanPanel` in that interpreter world at lines 103–108. The shell-owned hub remains the one constructed by `TabShellHost.wiring` for shell surfaces.

Facade attempts subscribe to their session ledger job key and forward canonical `EventEnvelope.toJson` strings through the existing `TextRenderSink`/`Consumer[String]` queue (`FacadeOps.scala:201–207`, `ChatLayoutSink.scala:91–97`). The shell decodes ADR-024 JSON and renders sourced `BudgetChanged` values (`Main.scala:81–111`). Plan snapshots are projected to JSON (`PlanTab.scala:61–83`), sent through the same string queue, and decoded into the tasks view and shell-owned auxiliary provider (`Main.scala:67–70, 113–169`). There is no runtime class crossing the REPL classloader boundary.

The chat shell accepts `:plan <task>`, runs the session's actual `PlanSession`, and exposes its proposal through the task view and `:aux`. Before a proposal exists, the view says `no plan started`; malformed snapshot payloads render as unavailable. Budget output appears only after a real ledger event.
