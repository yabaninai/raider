## Resulting behavior

The schema-version-2 carrier continues to roundtrip four discriminator kinds
through run.json and events.jsonl. The decoder now rejects payload keys other
than the provisional `digest` fixture field and refuses a non-string digest.
For a mixed stream, unknown `type` values with schemaVersion 2 return
`UnknownKind`; schemaVersion-1 event objects remain opaque and byte-preserved.

This is deliberately a narrow fixture/carrier boundary, not validation of the
RAI-164 domain payloads. RAI-164's concrete types/field lists are absent from
this baseline, while ADR-034 §5 explicitly describes its evidence fields as
conceptual. The card does not explicitly authorize deferring SDLC-WIRE-02, so
this round adds only the field-level boundary supported by the current fixture
and records full typed-domain validation as blocked pending RAI-164's frozen
schema. The current boundary should not be mistaken for accepted RAI-164 types.

  `docs/work/records/RAI-164.md` is absent. The only concrete current payload

  valid domain field for those kinds. Required domain fields and types cannot be
  accurately encoded without inventing RAI-164's contract. RAI-164 completion
  must replace this provisional schema with per-kind schemas and establish the
  complete SDLC-WIRE-02 boundary.

  actual evidence production.
- Independent review and integrated-candidate gates remain outstanding.
