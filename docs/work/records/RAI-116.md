## Resulting behavior

Authored [ADR-029](../../adr/ADR-029-workflow-sdk.md) — the Scala Workflow SDK

Decision summary (five areas, §2/§3 of the ADR):

1. **D1 authoring/launch** — first-class path is ordinary Scala over the
   existing lazy `Task`/`Program` and composition verbs, run locally and in
   non-TTY generic CI through ONE ZIO-native launch capability assembled from
   explicit backend/tools/policy/limits (working name `WorkflowLaunch`,
   illustrative, non-frozen). Alternatives rejected against actual code:
   ZLayer-first (constructor mismatch, instance isolation), raw
   loop/admission/jobs exposure, REPL/CLI facade reuse
   (`FacadeOps.scala:67` blocks via `Runtime.default`; process-global state).
2. **D2 wire** — BundleWorkflow v1 stays the frozen `String→String` boundary;
   typed in-process composition is never a typed wire. Honest comparison uses
   verified facts: the no-arg SPI has no service injection
   (`bundle.scala:92-100`), every existing bundle example is deterministic
   (`examples/user-guide/bundle/TaskSummary.scala`), and the runner admits
   bundle programs as one opaque outer Model slot settling `MicroUsd(0)`
   (`HeadlessRunner.scala:624-647`) — so an agent workflow cannot run behind
   v1 today; a wire change requires a new `schemaVersion` + ADR + migration.
3. **D3 one root/admission/ledger per run** — one launch instance owns one
   root/`Admission`/`BudgetLedger`/`JobManager`; admission discipline is
   single per dispatch path (loop-owned vs one opaque outer slot); nested
   Model takes deadlock on `maxLLM=1` (fixture 2026-10-04, ADMISSION NOTE in
   `HeadlessRunner.scala`).
4. **D4 scope/ownership/cancellation/errors** — caller's ZIO scope owns the
   capability; close reports `ScopeCloseReport`; cancel mechanics and
   structured `RaiderError` families unchanged; no durable resume.
5. **D5 classpath + compatibility** — core/runtime/dsl/providers (+optional
   tools) only; no repl/compiler/JLine/cli/testkit on main classpath; pinned
   Scala 3.9.0/ZIO 2.1.26/JDK 21; experimental with migration notes; no
   backward-TASTy promise below 3.9.0 without compile proof.
