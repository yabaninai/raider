## Resulting behavior

Anthropic Messages wire (`/v1/messages`) now carries tool DEFINITIONS —
closing the W05 gap ("Tool definitions on wire" audit line, 2026-10-12):

- `AnthropicMessagesBackend.encodeRequest` serializes every
  `ModelRequest.tools` entry as one NATIVE tools array element
  `{"name","description","input_schema"}`; the schema rides VERBATIM from
  `ToolDefinition.parametersJsonSchema` — the SAME source as the OpenAI wire
  (OpenAIChatBackend Wire.encodeRequest), no second hand-written schema. N
  tools in the request → N entries, order preserved. Wire fragment from the
  fixture (AnthropicToolDefinitionsSpec, exact-string pin):
  `"tools":[{"name":"lookup","description":"Look it up","input_schema":{"type":"object","properties":{"q":{"type":"string"}},"required":["q"]}},{"name":"calc","description":"Calculate","input_schema":{ "type": "object" }}]`
- Empty tools list → request WITHOUT a `tools` field, byte-for-byte identical
  to the pre-change format (pinned by exact-string unit assertions for
  streaming=false and streaming=true, and by a stand capture asserting no
  top-level `tools` key).
- Invalid schema (empty/blank, unparsable JSON, valid JSON but not an object)
  → typed `RaiderError.InputValidation` (RA-INP) from `encodeRequest` — which
  both stream paths call BEFORE any HTTP send; the stand fixture proves
  `handle.requests.isEmpty` (nothing reached the wire), no silent degradation.
- Consistency with the existing tool_use/tool_result mapping unchanged: the
  loop envelope (role "tool") still becomes a NATIVE `tool_result` block with
  preserved `tool_use_id` correlation — now correlating against definitions
  that are actually on the wire. Response decoding (tool_use →
  ToolCallReady) and SSE parsing untouched.
- Streaming compatibility: tools ride the `"stream":true` request too;
  existing SSE invariants hold on the definition-gated stand (2-byte
  fragmented frames, assembled `input_json_delta` fragments, cumulative usage
  counted ONCE, honest stop_reason tool_use/end_turn).

No public API/schema changes: `ToolDefinition`/`ModelRequest` are reused as
is; the change is confined to the anthropic wire encoder plus its fixture.
OpenAI wire untouched. No live/paid calls — stand is a local JDK HttpServer
loopback stub.
