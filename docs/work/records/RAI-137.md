## Resulting behavior

The UX baseline harness now returns success only when both latency and REPL-start measurements completed. An unavailable classpath is recorded in the JSON report, emits its reason on stderr, and exits 3. `--allow-skip` opts into an informational success and records `gate_status: informational-skip`; measurement failures take precedence over skips and exit 1. Report path creation and persistence errors return 2. The component-stage `perf` profile is additive and invokes the hardened harness without `--allow-skip`; it produces baseline measurements without thresholds.
