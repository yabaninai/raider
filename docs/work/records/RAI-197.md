## Review-fix round: map item scope and bounded schemas

Two contract gaps found in review are addressed in the Proposed ADR and fixture
corpus. In a map template, `#/item` is the current array element, typed exactly
as the source array's `items` schema; `#/index` is its non-negative integer
index. Template input references are scoped to those roots and descendants, so
the fixture agent now receives `#/item`, not the complete source array. A
template reference such as `#/inputs/items/0` is refused as
`map-template-scope-escape`.

Frozen v1 schema/document bounds are 262144 UTF-8 document bytes, schema depth
16 (each declared input/output schema root is depth 1), and 64 enum values per
schema node. The JSON Schema explicitly unwinds schema-subset recursion through
depth 16; enum arrays have `maxItems: 64`. Preflight refusal IDs and diagnostics
cover `schema-depth-exceeded` and `enum-size-exceeded`.
