# RAI-191: work record

Status: partial. Date: 2026-10-24. Baseline commit/source: `c6250cfff4f99d56c46702cc288ca9ad1feaf09a`.

## Resulting behavior

The own chat renderer now converts markdown headings, unordered/ordered lists,
and fenced blocks on every bounded snapshot, so partial streaming snapshots can
be rendered again without retaining parser state. Scala and JSON code receives
hand-rolled ANSI token colors; unified-diff-shaped code lines receive add,
remove, and hunk colors. Dark/light frame colors and Unicode box-drawing were
added. ESC in message text is made visible before rendering. Existing row-diff
rendering remains the redraw path.

The renderer currently classifies/colorizes diff rows locally; it does not call
`raider.tools.files.edit.UnifiedDiff`, because `raider-ui` does not depend on
`raider-tools` and changing the coordinator-owned build graph is outside this
card's allowed paths. The card-required real PTY turn combining markdown, code,
and diff has not been implemented or evidenced; the allowed paths do not
include the existing REPL PTY fixtures/stand.
