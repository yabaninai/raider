## Resulting behavior

Added an internal runtime-owned `RerunBackend` request/result seam. Live reruns accept a fresh prompt and a `LineageSnapshot.Snapshot`; the snapshot generation and recorded graph travel as provenance. The CLI's `ReplayHarness.liveBackend` runs the configured backend through `AgentLoop`, never using `ReplayModelBackend` for the live call. The result carries the new answer and fresh graph for live-vs-recorded reporting. Budget errors stay typed. ZIO cancellation interrupts the run, removes its isolated copy, and does not imply durable resume or mutation replay.
