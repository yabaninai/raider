## Limitations / blockers

- **Live-wire gated** (card non-goal): all unified evidence is offline and
  deterministic. No live provider run through the unified path has been
  performed; the guides say so explicitly.
- **No live phase emission** in the product runtime yet (frozen ADR-024 hub
  seam; `LoopEvents` has no phase surface) — corpus phases are frozen wire
  payloads authored through the real codecs; the RAI-145 machinery fixture
  inserts them as a documented stand-in. A phase-emission wiring card is the
  natural follow-up (candidate registered in this record and in the guides).
- **Headless coder-agent delegation wiring** is still open (RAI-144
  limitation 1, agent-registry policy surface); a plain `raider run` today
  produces a single-root v1 stream. The guides state this so users do not
  expect unified exports from the current product entry point.
- **Per-level anchoring** (nested delegation chains) is a precondition that
  has not shipped; corpus `case-2-delegation-tree` pins only the projection
  semantics for deeper nesting.
- **No unified lineage-data writer**: `RunLineageArtifacts` refuses
  phase-bearing graphs typed, so the guides never claim or quote a unified
  `lineage-data.json`; the only unified data surface shown is the frozen
  joined stream + dataRef keys. (A real delegation join without phases
  writes lineage-data v2 with `provenance` — stated, with the RAI-144
  citation.)
- The rendered artifact is a real generator OUTPUT pinned to the corpus, not
  a capture of a live multi-job run (the corpus README's own provenance
  statement, inherited by the artifact README).
- Evidence binds to the manifest's per-file source snapshot (mode
  `git-status`, run IDs in the commands table); this record is operational
  text written after the gate runs. Gate classification for docs/** +
  examples/** selects the `docs` profile (component stage); compile evidence
  for the example was produced by the exact bootstrap command
  (`scripts/build/user-ci.sh`) rather than assumed from the gate set.
