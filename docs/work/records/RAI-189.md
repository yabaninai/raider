# RAI-189: work record

Status: partial. Date: 2026-10-24. Lane baseline: `bcd1b58`; coordinator mandate merge: `e4d7a44`.

## Resulting behavior

The typed approval API and guarded-tool wrapper now live in `modules/runtime/src/main/scala/raider/runtime/tools/approval/ToolApproval.scala`, adjacent to runtime tool-dispatch policy. Both `raider-repl` (`FacadeOps` + `ChatLayoutSink`) and `raider-cli` (`ChatLoop`) consume the shared runtime API without a module cycle. `ToolApproval.guard` wraps only tools stamped `RecoveryClass.Mutating`; explicit `Approve` invokes the original tool, while explicit `Deny` and a missing hook fail closed with `RaiderError.ToolDenied` (`RA-TOOLDENY`). The CLI asks for a typed `yes` response at each mutating invocation; every other response or input failure denies. Read-only and idempotent tools are not prompted. The launcher registry is not expanded.

Tool cards remain bounded and render through the existing renderer bridge. The approval wait uses the shell's existing JLine input/read loop and render writer.

## Changed paths

- `modules/runtime/src/main/scala/raider/runtime/tools/approval/ToolApproval.scala` — typed approval context, decision, hook, and shared mutating-tool wrapper.
- `modules/repl/src/main/scala/raider/repl/facade/ReplSession.scala` — optional session binding defaults to absent; uses the runtime hook.
- `modules/repl/src/main/scala/raider/repl/facade/FacadeOps.scala` — ordinary REPL facade guards tools at `AgentLoop.runText` wiring; typed refusal when no approver is bound.
- `modules/repl/src/main/scala/raider/repl/ChatLayoutSink.scala` — bounded approval card, one pending decision, token-bound resolve, cancellation cleanup.
- `modules/cli/src/main/scala/raider/cli/chat/ChatLoop.scala` — CLI ChatLoop uses the shared guarded tool registry and explicit `yes`/default-deny prompt.
- `modules/repl/src/main/scala/raider/repl/Main.scala` — chat binding and `:approve <token>` / `:deny <token>` routing through the shell input loop.
- `modules/repl/src/test/scala/raider/repl/ToolApprovalSpec.scala` — approve, deny/headless refusal, and read-only-no-prompt cases.
- `docs/work/records/RAI-189.md` — this record.

No core/runtime or wire schema was changed.
