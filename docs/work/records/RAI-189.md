# RAI-189: work record

Status: partial. Date: 2026-10-23. Baseline commit/source: `a4485f1a18fc60d43509d215742098e91da1525f`.

## Resulting behavior

The inherited changes route tool-call start, completion, and refusal summaries to the existing chat render sink when `echoStream` is enabled. The chat sink bounds argument and outcome text, appends status messages to its bounded history, and publishes frames through the existing renderer bridge. The focused unit fixture confirms a running and completed `fs_read` card appear in captured renderer output.

Inline approval is not implemented. ADR-028's existing `PlanSession` approves a structured plan proposal and starts a separate execution job; it does not expose a per-tool-call approval edge for the ordinary `AgentLoop` dispatch path. The inherited code does not block mutating tools, obtain an input decision, or route approval/denial to that dispatch. Treating display text or a new renderer callback as approval would bypass the required owner decision and is not an acceptable substitute. Consequently, apply/deny, policy refusal, duplicate-decision, and the three requested transcript-proven PTY scenarios remain unverified.
