## Resulting behavior

The testkit retains `LocalForgeStand` as a deterministic, in-memory fast protocol layer and adds `DisposableGitForgeStand`, which initializes an isolated local repository and performs commit, pull-request branch/status, merge, ref inspection, stale-ref detection, and read-only reconciliation against real local Git refs. The stand does not contact a remote, push, or claim exactly-once behavior. Temporary repositories are removed by closing the stand.

An injected async commit exposes `Pending` while a ZIO-clock-controlled window elapses, then applies the mutation with `TimedOutUncertain`. Blind retries remain blocked; read-only reconciliation observes the applied operation. Existing typed stale/conflict/duplicate/unknown-after-effect/retry cases remain.

## Limitations / risks

No real forge, network, credentials, push, workflow runtime integration, or exactly-once behavior is implemented. Pull-request status is local stand state associated with a real temporary branch, not a hosted forge status. Git must be installed. Disposable Git failure injection covers stale actual refs and happy-path PR/merge; injected conflict/duplicate/unknown outcomes remain in the fast in-memory layer. `RAI-169` review and final gate results are outstanding at freeze.
