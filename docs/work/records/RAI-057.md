## Resulting behavior

No behavior change. The lane verified that the accepted P2.A slice fully
satisfies the card at the lane tip:

- **Immutable session identity** — `TabId` assigned once at `create`, never
  mutated (`SessionRegistry.scala`).
- **Per-tab state** — UI-local `draft`, bounded `history` (cap 200 folded
  snapshots) and `scrollback` (cap 500 text lines), drop-oldest eviction with
  honest `evicted` counters (`HistoryView`/`ScrollbackView`); a `Terminal`
  event always lands in the folded snapshot, so eviction never loses terminal
  status.
- **Unread counters** — bumped for every event delivered to a non-focused tab;
  reset on focus; creation race window closed (review fix D1-1).
- **Focus model** — `focus`/`focusNext`/`focusPrev` are ONE-call switches
  (card bound: ≤2 actions) and are UI-state only: no publish, no cancel, no
  owner/budget/policy mutation (invariant test).
- **Input = RAI-055 events, output = tab state, no rendering** — one hub
  subscription per tab; envelopes deduped by `(jobId, seq)` and reordered by
  `seq` before folding; reads return `TabView`/`HistoryView`/`ScrollbackView`;
  close returns the typed `CloseDecision` (`RunningChoice`/`Closed` + lineage
  set); unknown ids are typed `RegistryError`.
