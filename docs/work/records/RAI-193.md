## Resulting behavior

`scripts/release/local-jvm-release.sh <semver>` builds the assembly with
`make raider-jar` and invokes `LocalReleaseHandler` using the one-shot Scala
driver in `scripts/release/LocalReleaseDriver.scala`. The driver composes
candidate-bound passed-build, acceptable-review, and applied-integration
records; creates the standard checkpoint request and matching decision; and
dispatches the existing checkpoint and local release APIs. Distribution
artifacts include the actual assembly, launcher, Homebrew formula, and Scoop
manifest. The shell driver verifies checksums, rendered formula version/JAR
hash, the Scoop launcher variable, and runs install smoke from the versioned
release directory. The Scoop source uses `RAIDER_VER` so version substitution
does not corrupt the launcher's environment-variable identifier.
For Git worktrees, the shell entrypoint temporarily exposes the actual
per-worktree Git directory to satisfy the existing release handler's
directory-only `.git` check, then restores the pointer on exit.

The approval basis is explicitly the local owner. Build evidence is the local
`make raider-jar` output, while review and checkpoint approval represent the
owner's self-authorization for a local-only distribution. There is no network,
remote reviewer, hosted release, or independent verification claim.

Chosen version: `0.1.0`, intended as the first local distribution release.
The changelog entry is generated by `ReleaseStage` when the successful local
release is materialized. The version directory and `v0.1.0` tag remain local
worktree state.

## Limitations / blockers

The artifact URLs in formulae describe a future hosted location; local release
does not upload or assert that those URLs exist. Homebrew execution and Windows
Scoop runtime behavior are not proven by the macOS clean-prefix smoke. The
checkpoint evidence is owner self-authorization and must not be represented as
an independent review.
