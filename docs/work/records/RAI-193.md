## Result

`scripts/release/local-jvm-release.sh 0.1.0` runs `make raider-jar`, compiles
the one-shot source under `scripts/release/LocalReleaseDriver.scala` into the
CLI for that invocation, and calls `LocalReleaseHandler`/`ReleaseStage`. The
driver builds a candidate identity, accepted build/review/integration records,
the standard checkpoint request, and a matching local decision. Checkpoint
current-state validation and the local release handler run before distribution
staging.

The trust basis is local-owner authorization. The build record reflects the
observed local assembly, and review/checkpoint acceptance is the owner's
self-authorization. No remote reviewer, network approval, publication, or
deployment is claimed. The script temporarily exposes the resolved per-worktree
Git directory to satisfy the existing directory-only `.git` precondition, then
restores the pointer on exit. The tag is attached to the release candidate
revision and remains local.

The first release invocation exposed two real rendering defects: global
`VERSION` replacement altered the Scoop `RAIDER_VERSION` and launcher
`VERSION_FILE` identifiers. The generated local output/tag/changelog were
removed, templates were corrected, and the release was regenerated. The final
driver smoke uses the staged launcher and staged JAR, not build-tree inputs.

## Earlier failed attempts and limitations

- Initial invocation was refused because the worktree has a `.git` pointer
  file; the driver now temporarily uses the actual worktree Git directory and
  restores the pointer through an exit trap.
- A later run exposed a dirty-tree check caused by storing the temporary
  pointer backup in the checkout; the backup now lives inside Git metadata.
- Template inspection rejected an intermediate generated release and that
  run's local tag, directory, and changelog were deleted before final
  regeneration.
- Formula URLs point at a future hosted location; this local release does not
  assert the URLs exist. Homebrew execution and Windows Scoop runtime behavior
  were not tested on this macOS host.
- Coursier is not installed in this environment. The release smoke verified the
  clean-prefix Java fallback; missing/incompatible-JDK and malformed-release-
  metadata negative cases were not run. The unit suite covers staged release
  interruption, but a signal-driven install/release smoke was not run.
- Checkpoint/review is local-owner self-authorization, not an independent
  review. Release output/tag are local-only.
