## Limitations / blockers

The implementation does not close the full card. In particular, final required-artifact write failures still travel through the existing `orDie` path instead of being converted to exit 27; helper precedence is not wired into `HeadlessRunner`; no real advisory/blocking process outcomes are exercised; `result.json` has no additive verdict fields; and write-failure, corrupted/missing artifact, and finalization interruption process tests remain pending. XML escaping checks are helper-level, not checks against captured hostile process output. The passing broad profiles therefore do not imply full RAI-186 acceptance.
