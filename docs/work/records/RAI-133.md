## Resulting behavior

- Anthropic `tool_result.content` is now a STRUCTURED block array —
  `[{"type":"text","text":<rendered payload>}]` (Anthropic Messages API
  shape). Previously `content` carried the raw loop payload as an arbitrary
  JSON value, which is invalid wire for object payloads. The payload JSON is
  rendered compactly and carried VERBATIM inside `text` (bit-for-bit
  recoverable; a JSON-string payload renders with its quotes — that quoting
  is part of the payload). `tool_use_id` correlation and the decode side
  (tool_use) are untouched; the OpenAI encode path is untouched.
- TRC-03 cross-wire parity: the SAME scripted tool scenario (user task →
  model asks `lookup` → local echo tool → final answer) runs through the
  SAME `AgentLoop` over BOTH local stands — OpenAI-compatible
  (`modules/provider-chat` sibling dependency) and Anthropic. Identical
  observable semantics asserted per wire and across wires: same final
  answer, attempts == 3 (2 model + 1 tool), tool payload visible on each
  wire (role "tool" message vs native tool_result block), settled ledger
  (`reservedActive == 0`), no permit leak; 3 repetitions pin determinism.
