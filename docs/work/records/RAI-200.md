## Resulting behavior

Added Proposed ADR-037 specifying the bounded, language-neutral, opt-in local
JSON-lines process protocol and a fixture corpus for RAI-201. The proposal
defines handshake/version/capabilities, submit/observe/cancel/terminal messages,
single-root ownership, request-ID limits, frame/queue bounds, Unicode/framing,
EOF/broken-pipe behavior, cancellation acknowledgement versus cleanup, exit
codes, artifacts, secret handling, and uncertain process-death recovery. The
existing headless runner's no-stdin behavior is explicitly preserved.

No adapter implementation, product API/schema, command, gate registration,
SDK, or runtime behavior was added. ADR-037 remains Proposed pending independent
review.
