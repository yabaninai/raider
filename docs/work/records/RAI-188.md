## Resulting behavior

Added an optional `raider.repl.Main --chat` entry. It uses the existing Scala REPL/backend loop, gives `ReplSession` an additive typed `TextRenderSink`, and sends model text deltas to `ChatLayoutSink`/`ChatAnsiRenderer`. If the sink is absent, `FacadeOps` retains its existing direct-console delta path. Chat history remains bounded; `:scroll-up` / `:scroll-down` move the bounded viewport. `:aux`, `:chat`, `:tabs`, `:help`, and `:quit` are reachable. JLine owns the input line and history. The existing `--tabs` entry and no-flag Scala REPL path remain unchanged.

No ADR-024 event payload/schema or dependency changed. The scripted mock backend is used by acceptance; no paid/live calls were made.

## Limitations / blockers

The shell is foreground/synchronous while a model request runs. It does not support editing a second draft during generation or cancellation of that generation. Resize, paste/multiline, Unicode input, terminal-capability fallback, and changing terminal dimensions are not proven by this lane's PTY. Thus TUIX-B1-02 and TUIX-B1-03 are partial, and the full RAI-188 card is not complete. The test PTY starts the real product entry under `/usr/bin/script`, uses a UUID-isolated temporary HOME/work directory, and pins `RAIDER_PROVIDER=mock`.
