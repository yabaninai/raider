Status: partial; B1-02 and B1-03 acceptance is not complete. Date: 2026-10-23. Baseline commit/source for this round: `30aa65b060ce4770f9ec5bee513b5603a89662ba` on `lane/rai-188`.

## Resulting behavior

The `--chat` entry now detects a dumb/unsupported terminal and reports an explicit fallback to the ordinary line REPL instead of starting the custom ANSI surface. Scala string escaping now preserves newline, carriage-return, and tab characters as string content when prompt text is embedded in REPL source. The product chat PTY fixture exercises Unicode input containing multibyte and wide characters, the unsupported-terminal fallback, terminal shutdown output, and existing streaming/chat controls.

An asynchronous generation/input prototype was rejected after PTY execution showed concurrent renderer/JLine output corruption and early process exit. It was removed; the shipped shell remains synchronous and does not claim generation cancellation or in-flight draft preservation.

No dependency, ADR-024 payload, or public contract changed. Tests use only the scripted mock backend; no paid/live calls were made.

### Follow-up round (baseline `30aa65b`)

The single-writer prototype explored in this round was not retained. It moved input to a queue and attempted to drain model render output from the console loop, but real PTY execution did not establish reliable bracketed-paste/escape handling or draft submission while a generation fiber was completing. One run timed out after four minutes; another produced assertion failures and a transcript where the paste delimiters appeared as literal prompt text. This is failed evidence, not a pass. Product source was restored to the baseline, so this round changes no runtime behavior.
