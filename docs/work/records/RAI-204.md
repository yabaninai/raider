## Resulting behavior

Documented a clean-prefix headless CLI installation from a local JVM release,
Java/version prerequisites, Coursier-vs-Java launcher behavior, mock first-run
invocation, per-run artifact location, current CLI help limitation, and the
boundary between the installed headless JAR and source-built REPL/tab shell.
README and user guides now route new CLI users to the installed path and keep
source checkout setup separate. No CLI/runtime behavior changed.

The assigned worktree did not contain the RAI-193 `artifacts/release/0.1.1`
directory. Its local `v0.1.1` tag already existed, so that version could not be
regenerated by the guarded release driver. Generated local-only `v0.1.2` from
the committed worktree with the RAI-193 driver, then installed and exercised
that exact staged artifact. This is engineering evidence for the installation
path, not a claim that v0.1.2 was published or that the exact earlier 0.1.1
artifact was tested.

Round-1 review fix: replaced the unsupported `--help` and `run --help` invocations
in the maintainer JVM-distribution guide with the documented mock `run` form for
both direct Java and Coursier launch. The guide now states the help limitation
and links to onboarding. No CLI behavior changed.

## Limitations / blockers

- No exact 0.1.1 release directory was present in this worktree; only its
  historical tag and acceptance record were available. The verified artifact
  is a local-only rebuild under 0.1.2, not a published artifact.
- `raider --help` and `raider run --help` are unsupported today. No CLI affordance
  was added because the card's allowed paths exclude product code.
- The mock scout returns fixed text rather than inspecting the workspace. Its
  verified benefit is a working installed invocation and inspectable artifacts,
  not useful model output.
- The TUI remains source-built; the installed headless JAR excludes the Scala
  compiler and JLine. Formula templates and URL shapes do not prove hosted
  distribution, Homebrew availability, or Windows support.
- Human usability target, Homebrew/Scoop installs, hosted artifact retrieval,
  and interruption during the CLI run were not tested.
