## Resulting behavior

The REPL now ships as an installed distribution: `sbt raiderReplDist` assembles `modules/repl/target/scala-3.9.0/raider-repl.jar` (fat jar, main class `raider.repl.Main`, includes `dotty.tools.repl.ReplDriver`, `dotty.tools.dotc.*`, `org.jline.*` and the full `scala-library`) and stages a distributable layout `raider-repl-<version>/` containing the executable `raider-repl` launcher, `raider-repl.jar`, `README.txt`, `version`, and `SHA256SUMS`, plus a fixed-timestamp `.zip` archive. A user who unpacks the archive, runs `chmod +x raider-repl` and launches the script gets a real terminal Scala REPL (banner `engine : scala3-repl 3.9.0 (in-process compiler)`; `val x = 1` prints `val x: Int = 1`) without ever touching the source tree; the headless `raider-cli.jar` remains compiler-free (its byte pins in `contracts/acceptance/cross-ecosystem/expected/golden-checks.json` are untouched).

Preflight layering, from outermost to innermost:

1. Launcher script (`raider-repl`, POSIX sh): exits 21 with a one-line diagnostic on stderr when the distribution jar is missing/unreadable (`distribution jar not found: <path>`), when no usable `java` is found or the local `java` is older than 21 (`raider-repl: Java 21 or newer is required`), or when `jar tf` cannot find `dotty/tools/repl/ReplDriver.class` (`distribution jar lacks the in-process Scala compiler (<marker>): <path>`). `--version`/`-V` prints `raider-repl <version>` and exits 0 without starting the JVM. `RAIDER_REPL_JAR` overrides the sibling-jar lookup for nonstandard installs. All checks pass control to `exec java -jar ...`, so SIGINT/SIGTERM exit codes (130/143) propagate unchanged from the JVM.
2. Staging library (`raider.repl.dist.ReplDistribution`): refuses to stage a jar whose central directory lacks `dotty/tools/repl/ReplDriver.class` (packaging-side mirror of the runtime preflight), verifies/repairs POSIX mode on the launcher, writes sorted GNU-compatible `SHA256SUMS`, and is idempotent (stale files in the target are cleared). Refusals are Scala exceptions, so the sbt task fails with a bounded message.
3. JVM preflight (`raider.repl.Main.preflightCompilerClasspath()`): before any REPL wiring, checks `dotty.tools.repl.ReplDriver`, `dotty.tools.dotc.core.Contexts`, `org.jline.terminal.Terminal` via `Class.forName(..., initialize = false)`; on absence prints exactly one stderr line (`raider-repl: the in-process Scala compiler is missing from the classpath (first absent: <class>). Launch the REPL through the installed distribution launcher (raider-repl).`) and throws `IllegalStateException`, so a compiler-less classpath cannot hang or half-start the REPL (this is the `java -cp raider-cli.jar raider.repl.Main` adversarial case; exit code is the JVM's uncaught-exception exit, deliberately unspecified by the card).

Test coverage (`raider.repl.dist`, 12 tests): staged-layout completeness/executable bit/SHA256SUMS verification, zip round-trip through the unpacker, staging idempotence, staging refusal of a compiler-less jar, launcher `--version`, clean-install piped eval of real Scala in a fresh HOME (non-TTY), launcher SIGTERM → exit 143 (non-TTY), launcher adversarials (missing jar → 21, compiler-less jar → 21), direct JVM without compiler → preflight diagnostic and nonzero exit, and two PTY tests driving the installed launcher over a real pseudo-terminal (prompt-driven eval; SIGTERM inside PTY → exit 143, bounded).

## Review fixes (R-1/R-2)

Verdict APPROVE-WITH-REQUIRED-FIX on commit `8ee98a5`; fixes implemented on `lane/rai-262` (amend, not history rewrite — sections above keep the pre-fix values, superseded here).

- R-1 (required): `ReplDistribution.sha256Hex` used `f"${b & 0xff}02x"` (missing `%`), so staged SHA256SUMS hashes rendered as decimal bytes + literal `02x` (the review's proof case: the README.txt digest `8347ea9bff61618019c257918b17e3c0aa8ff5a1fc52c52885f8f403ce571719` appeared as `13102x7102x…`). Fixed to `f"${b & 0xff}%02x"`. Verification is now independent of the fixed routine, in two layers: (a) the staging spec asserts every SHA256SUMS hash matches `[0-9a-f]{64}` and cross-checks each digest via a second code path (one-shot `MessageDigest.digest(byte[])` formatted with `java.util.HexFormat`, deliberately not `sha256Hex`), plus a `shasum -a 256 -c SHA256SUMS` run against the staged layout; (b) the clean-install smoke path verifies the UNPACKED layout with the platform tool (`shasum -a 256 -c`, `sha256sum -c` fallback; a tool that runs and fails is a failure, no silent fallback retry). Negative control: a one-byte `README.txt` tamper after unpack makes `shasum -c` exit 1 with `README.txt: FAILED` (`modules/repl/target/rai262-pty/real-dist-shasum-tamper.log`, sha256 `26be9330545f5b3bebf59855f611c0cdb0fcc95b407a25b01487dd570db2fea7`).
- R-2 (required): the PTY SIGTERM leg now asserts the exit CODE, per the review's preferred remedy. `InstalledReplPtySpec.destroyDescendantAndAwait` returns the `/usr/bin/script` wrapper's exit status (the launcher is `exec`-ed into the REPL JVM, making it the wrapper's direct child, and `script(1)` propagates the child status); the test asserts `wrapperExit.contains(143)` and is renamed to "SIGTERM inside a PTY session exits 143 through the PTY wrapper (bounded)". Outcome: the assertion PASSES on this host — the wrapper exit code proved stable, so no fallback to the weaker "bounded descendant termination" claim was needed.
- Advisories: A-1 — the launcher diagnostic in "Resulting behavior" now reads exactly `raider-repl: Java 21 or newer is required`; A-2 — the 40-hex value in Commands is labeled as the sbt-assembly SHA-1 jar hash and marked superseded; A-3 — changed-paths notes the `root/scalafmtSbt` whitespace reflow of `build.sbt`.

## Limitations / blockers

- The one-shot manual PTY probe (`printf ... | /usr/bin/script -q /dev/null ...`) with all keystrokes typed ahead of the first prompt does not complete under jline raw-mode input; this is a limitation of the burst-input probe pattern, not of the distribution — the automated `InstalledReplPtySpec` drives the same launcher over a real PTY with post-prompt interactive sends and passes, including SIGTERM/143. Coverage of typed-ahead input is left to the existing REPL input tests; no product change was made for it.
- The manual PTY transcript `modules/repl/target/rai262-pty/real-dist-pty.log` is an artifact of the aborted probe and carries no acceptance value; it is excluded from evidence and lives only in the gitignored evidence directory.
- The installed REPL bundles the full Scala 3 standard library and compiler (~size visible in the jar); the headless CLI artifact remains compiler-free, and the two distributions' contents are pinned by the existing cross-ecosystem goldens (unchanged).
- Live provider backends are not wired in this slice (banner says `fixture/mock`); this card adds packaging only and inherits that state.
