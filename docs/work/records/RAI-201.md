## Resulting behavior

New opt-in local process adapter `raider process-api` (ADR-037 + contracts/process-api README):
one stdio JSON-lines protocol session wrapping at most one existing runtime root,
owned by the invoking process. Highlights:

- **Wiring**: `Main` gains a `process-api` subcommand (`--provider`, `--out-dir`,
  `--workspace`, `--coder`, `--model`, `--base-url`; opt-in only, no default route).
  Exit codes surface the settle verdict: 0 natural success, 20 protocol-fatal,
  26 uncertain (client-cancel / EOF-after-dispatch / dead channel), 143 SIGTERM
  (see `ProcessApiCommand`).
- **Session** (`Session.scala`): strict NDJSON frame loop (LF-delimited frames,
  ADR-037 §3); hello/helloAck negotiation with required-capability refusal;
  single-root submit → `accepted` → live observations → exactly one `terminal`;
  observe (cursor replay, `observe_failed` refusal allowed), cancel
  (`duplicate_submit` ownership guard, `cancelAck` in {accepted, already_terminal,
  not_found}), bounded structured errors. Settle-once machinery: the first of
  {natural completion, client cancel, EOF-after-dispatch, clean EOF, SIGTERM,
  protocol-fatal, dead channel} claims the settle mode and the honest exit code;
  later requests are absorbed. A naturally completing run gets a bounded (1 s)
  window to finish relaying its trailing events before the terminal frame is
  written, so the events.jsonl journal and live observations are complete
  (see Limitations note below). stdout writes are LF-terminated protocol frames
  only; nothing else ever writes to stdout.
- **Outbound** (`Outbound.scala`): bounded frame queue (64 frames / 4 MiB), receipts
  (accepted/error/cancelAck) never dropped — they backpressure the reader;
  progress observations coalesce under saturation and the next delivered
  observation reports `skipped {fromSequence, count}` (explicit gaps per ADR-037
  §5); the terminal has a reserved slot and is written last; every write is
  bounded by a stall watchdog — a non-draining or broken channel is declared
  dead and the session settles truthfully (exit 26), never looping on EPIPE.
  `terminalWrittenOrDone` is deterministic: `true` whenever the terminal bytes
  reached the channel, `false` only when the writer ended without writing it.
- **Framing** (`Framing.scala`): strict UTF-8 (REPORT on malformed input), strict
  JSON object frames, `FrameMaxBytes` = 1 MiB enforced before decode
  (`oversize_frame`, payload never echoed), `i += 1` loop fix, decode-failure
  messages never quote payload fragments (the zio-json error text is discarded).
- **Protocol** (`Protocol.scala`): versioned frames with exact field allowlists
  (`unknown_field` for submit option siblings, refusal before dispatch,
  value never echoed); `Protocol.correlation` surfaces best-effort `requestId`
  on decode-level error replies ("correlation where known", ADR-037 §3) without
  changing validation order.
- **RootRun** (`RootRun.scala`): reuses the existing runtime — `JobManager.start`,
  `AgentLoop.runText`, `EventHub` subscribe-before-start (loss-window-free),
  mock provider requires no credentials; a live provider requires the env
  credential path before any dispatch (RAI-064 preflight discipline).
  `buildRunResult`/`appendSchemaCheck` produce the run-result document
  (run-outcome + run-result-schema checks) validated before write.
- **Artifacts** (`Artifacts.scala`): per-invocation dir `<out-dir>/invocation-<id>`
  created at session boot; on settle writes `result.json` (manifest, files=4),
  `run.json` (run result, artifacts=3), `events.jsonl` (full journal), `summary.md`;
  artifact entries carry path/sha256/sizeBytes/provenance.
- **Contracts** (`contracts/process-api/README.md`): normative wire/README for
  the process protocol mirror (consumer-facing contract text).
- **Tests**: 32 unit tests (FramingSpec, ProtocolSpec, OutboundSpec — including
  queue saturation/coalescing/skipped-reporting, stall watchdog, deterministic
  `terminalWrittenOrDone`) + 13 real-child acceptance tests
  (`ProcessApiAcceptanceSpec`) launching the actual `raider process-api` child via
  ProcessBuilder (file-redirected stdin/stdout, mkfifo stdin, closed-pipe stdout)
  covering: XE-PROC-01 normal handshake (accepted, replayed+live observations,
  unique terminal agreeing with exit 0, artifacts on disk, stdout purity — every
  line parses as a protocol frame), XE-PROC-02 fragmented UTF-8 submit split at
  arbitrary byte positions including mid-code-point, oversize frame refused
  before dispatch (exit 20, no echo), refusal of secret-bearing field and unknown
  type (non-fatal, bounded, no secret echo, no root), broken pipe (exit 26, never
  success), XE-PROC-03 duplicate submit refused with first root keeping ownership,
  cancel mid-run (exactly one terminal, cancelAck accepted), clean EOF before
  submit (exit 0, no root, no terminal), EOF mid-frame (protocol error), SIGTERM
  → 143 graceful, SIGKILL → 137 with no terminal proof of completion, slow reader
  still receiving every frame.

Product defects found and fixed by the real-child acceptance suite during this
card (not present in unit-level behavior):

1. **Missing LF delimiter** in `stdoutSink` — frames were concatenated
   (`..."}{"protocolVersion"...`), so a strict NDJSON peer parsed nothing.
2. **`accepted` frame was defined but never emitted** by `startRoot`.
3. **Nondeterministic `terminalWrittenOrDone`** — `raceFirst` between two promises
   completed back-to-back on the writer fiber; when the race started after both
   were already done, the winner was a scheduling coin flip and a successful run
   could exit 26 (observed in acceptance run 5, fragmented case).
4. **Trailing-event loss on natural settle** — the settle interrupted the event
   forwarder before it drained the subscriber queue tail; observations
   (and events.jsonl lines) for the final events could be missing even though
   the run completed. Fixed by a bounded 1 s forwarder drain before the terminal
   frame for Natural mode only.
5. **Decode-level errors lost `requestId` correlation** — added
   `Protocol.correlation` (best-effort, validation order unchanged).

## Limitations / blockers

- `events.jsonl` journal and trailing observations rely on a bounded (1 s) drain
  window on natural settle; a pathological producer flooding > subscriber-queue
  capacity at completion could still lose tail events beyond the window (the
  terminal record and run-outcome check remain authoritative and are unaffected).
- The terminal-frame "written" check is deterministic now, but a channel that
  dies AFTER the terminal bytes are on the wire still reports exit 0 (bytes
  delivered) — by design; the client cannot be given more truth than the wire.
- Compile-fixtures required `scripts/bootstrap.sh` in this worktree (local m2
  toolchain under `artifacts/tools/m2` was missing; fixed by bootstrap run).
- Mock-provider coverage only for provider interaction (per card); live provider
  dispatch is out of scope and requires explicit budget/mode per repo policy.
- Temp evidence directories under `/var/folders/.../T/rai201-*` mix generations
  from earlier diagnostic runs; the authoritative evidence is the gate manifest
  and the two final acceptance logs listed above (current source fingerprint).
