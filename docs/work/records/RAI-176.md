## Resulting behavior

Streaming OpenAI-compatible Chat requests include normalized function tool definitions in the existing Chat wire format. Tool names and descriptions use JSON string encoding, parameter schemas remain JSON values, and an empty tool list still omits `tools`. The streaming request retains its existing stream options and token limit.

The local probe runs the actual streaming backend and AgentLoop against a scripted OpenAI-compatible Scala HTTP stand on an ephemeral loopback port. The stand accepts requests only when the expected tool definition is present, emits a streamed tool call, and the invoked tool creates a real temporary file. The probe asserts the file exists and its on-disk contents equal the tool-call arguments. This is a bounded local protocol probe, not an inference from locally loaded model weights. No local inference server binary or model weights were available; no remote or paid calls were made.

The focused suite passed 16/16 tests. The repeated probe command ran the full suite three times; each run passed 16/16, with the `LOCAL-MODEL probe` case passing on all three runs.
