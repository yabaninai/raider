Status: accepted. Milestone: M0. Dependencies: none.

**Scenario and contract.** Minimal reproducer: val/def/case class bindings, a shared runtime object through a classloader/prelude bridge, background fibers, JLine edit buffer, bundled headless invocation. Check Scala/JDK/ZIO/artifacts and HTTP/schema candidates; record exact versions, startup/memory, and the recommended adapter.

**Context.** runtime-contracts.md §1; product-repl.md §1,7,12; ci-runtime.md §3,6

**Allowed paths.** `experiments/repl-spike/**`, `docs/adr/**`, `docs/research/feasibility/**`. Tests live within the same module/contract areas. Clarify concrete files before assignment; expanding the path boundary requires a separate scope card.

**Acceptance.**

- Normal: SPIKE-01: clean startup, saved transcript and version inventory; separate headless process without terminal/compiler classpath.
- Error/adversarial: SPIKE-02: compile error preserves the previous binding; missing toolchain/artifact is explicitly unavailable.
- Cancellation/concurrency: SPIKE-03: Ctrl+C during foreground/await/idle and runner SIGTERM leave no orphan; background output does not corrupt the input line.

**Required gates.** Bootstrap: prerequisite/version inventory; actual compiler prototype run and packaged headless/PTY harness. Record exact argv/exit codes in the reproducer; a missing tool is not passed. The future quality runner is not yet required.
