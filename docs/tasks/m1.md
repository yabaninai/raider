**Scenario and Contract.** Close the RAI-032/033 fail-closed blocker the RAI-281 way: (1) add path_profiles coverage so ^vendor/ and ^THIRD_PARTY_NOTICES.md classify to a real profile instead of the unmapped-paths refusal; (2) add a vendor-audit gate (new python checker) that verifies every vendor/<corpus>/ carries pinned provenance — upstream ref, license, per-file sha256 manifest — and re-verifies the hashes, with typed failure codes, --self-test, and exit semantics 0/1/2; (3) update quality.py classify/select cases and self-test fixtures, including the gate-count pin; (4) document the gate and its mandatory activation stage in docs/quality-gates.md. Exact registry values are owner-ratified before merge (RAI-281 precedent): this card lands on a lane, gets independent review, and requires owner ratification.

**Context.** Both importer lanes ended with make quality-changed QUALITY_EXECUTE=1 exit 2: THIRD_PARTY_NOTICES.md and vendor/** map to no profile. The refusal is correct fail-closed behavior; coverage must be added by policy, not bypassed (RAI-281 precedent for CHANGELOG.md).

**Allowed Paths.** scripts/quality/**; scripts/quality-policy/registry.json; docs/quality-gates.md; docs/work/records/**.

**Acceptance.**

- Normal: VENDOR-01: a tree containing a valid vendored corpus passes make quality-changed QUALITY_EXECUTE=1 with vendor paths classified to a real profile and vendor-audit executed and passed.
- Error/adversarial: VENDOR-02: corrupting a vendored file hash, removing provenance, or omitting the notices entry fails vendor-audit with a typed code; unmapped-path refusal still fires for genuinely unmapped paths (fail-closed preserved).
- Cancellation/concurrency: No concurrency requirement; the checker is serial and deterministic over the pinned manifests.

**Required gates.** docs, self.

**Non-goals.** No loosening of existing profiles or thresholds; no change to protected verifier logic; no vendoring of new corpora (the corpora exist on lane/rai-032 and lane/rai-033); no build.sbt changes (coordinator-owned).

**Compatibility/rollback.** Gate-policy card; owner ratification required before merge; revert restores the pre-card refusal behavior.

**Deliverables.** Checker + registry entries + docs + self-test fixtures, work record with commands and exit codes.
