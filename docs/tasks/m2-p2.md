**Сценарий и контракт.** Pin MCP version/transports, lifecycle/auth/tools schema/artifact normalization, bounded timeout/output/permissions and server capability report. Discovery не execute tools и не предоставляет лишние rights.

**Context.** runtime-contracts.md §10,12; provider-protocols.md §2; quality-gates.md §3

**Allowed paths.** `modules/mcp/**`, `contracts/mcp/**`, `docs/adr/**`. Tests находятся внутри тех же modules/contract areas. До назначения уточнить concrete files; расширение path boundary требует отдельной scope card.

**Acceptance.**

- Normal: MCP-01: local fixture server tools/resources translated into typed registry and native loop.
- Error/adversarial: MCP-02: auth/schema/protocol mismatch/disallowed tool/server disconnect explicit errors.
- Cancellation/concurrency: MCP-03: cancel request/session close/late tool output status, no orphan server processes or widened child permissions.

**Required gates.** После foundation: make quality-changed; make quality-changed QUALITY_EXECUTE=1; make quality-profile PROFILES="static unit contracts transport tools security compatibility"; evidence verification с каждым required profile. full/release aggregates разрешены, если реально включают весь список. External prerequisites explicit; unavailable не passed.

**Non-goals.** Unlimited remote servers/plugins, protocol support без version conformance, bypass CI sandbox policy.

**Compatibility/rollback.** Frozen schemas/API и downstream fixtures не менять молча; versioned migration/ADR отдельно. Откат feature не replay side effects; persistent incomplete/uncertain artifacts сохраняются для reconciliation. Experimental/optional adapter выключается explicit capability flag.

**Deliverables.** Минимальный diff в allowed paths, перечисленные executable fixtures с actual IDs, обновлённый relevant contract/example, actual work record по template и текущий evidence/log hashes. Реальные платные вызовы/публикация не implied. Если задача слишком велика, перед coding разбить на независимые дочерние карточки; родитель принимает их совместный contract gate.
