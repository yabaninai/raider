# orders-billing — sample service

Small Scala service skeleton used for repository navigation exercises.

## Modules

| Path | Responsibility |
| --- | --- |
| `src/orders` | order intake and lookup |
| `src/billing` | invoices and payment tracking |
| `src/common` | shared value types |
| `config` | runtime configuration |
| `docs` | architecture notes |

There is no build wired up; this tree is used read-only for code search tasks.
